# 📋 Product Documentation

Product documentation serves as the **north star** for all engineering decisions. Every feature, API endpoint, and UI component should trace back to a product requirement defined here.

## Audience

- Engineering team
- Stakeholders
- Investors / advisors

## How to Update

1. Propose changes via PR with the `docs` label

3. Update the roadmap when milestones shift
