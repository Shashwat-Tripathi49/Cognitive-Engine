# User Stories

> Organized by persona and epic. Each story follows the format:
> _As a [persona], I want [goal] so that [benefit]._

---

## Personas

| Persona                         | Description                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Alex** (Knowledge Worker)     | Product strategist who processes large volumes of information daily and needs to synthesize insights across domains |
| **Maya** (Lifelong Learner)     | Graduate student and avid reader who wants to connect ideas across books, lectures, and personal reflections        |
| **Sam** (Creative Professional) | Writer and content creator who captures fleeting ideas and needs to find unexpected connections                     |

---

## Epic 1: Thought Capture

> _The ability to quickly and frictionlessly capture thoughts._

### Stories

| ID     | Story                                                                                              | Priority | Persona |
| ------ | -------------------------------------------------------------------------------------------------- | -------- | ------- |
| US-101 | As Alex, I want to capture a thought in under 5 seconds so that I don't lose ideas during meetings | P0       | Alex    |
| US-102 | As Maya, I want to write long-form reflections with rich text so that I can develop complex ideas  | P1       | Maya    |
| US-103 | As Sam, I want to tag entries with custom labels so that I can organize by project or theme        | P1       | Sam     |
| US-104 | As Alex, I want to capture thoughts via keyboard shortcut so that I never break my workflow        | P1       | Alex    |
| US-105 | As Maya, I want to attach links and references to my thoughts so that I can trace ideas to sources | P2       | Maya    |

---

## Epic 2: Discovery & Search

> _The ability to find and rediscover past thoughts._

### Stories

| ID     | Story                                                                                                          | Priority | Persona |
| ------ | -------------------------------------------------------------------------------------------------------------- | -------- | ------- |
| US-201 | As Alex, I want to search my thoughts semantically so that I find relevant entries even without exact keywords | P0       | Alex    |
| US-202 | As Maya, I want to browse thoughts by timeline so that I can see how my thinking evolved                       | P1       | Maya    |
| US-203 | As Sam, I want to filter by tags, dates, and mood so that I can narrow down to specific contexts               | P1       | Sam     |
| US-204 | As Alex, I want to see "related thoughts" when viewing an entry so that I discover connections                 | P0       | Alex    |

---

## Epic 3: Intelligence & Insights

> _AI-powered features that augment cognition._

### Stories

| ID     | Story                                                                                                         | Priority | Persona |
| ------ | ------------------------------------------------------------------------------------------------------------- | -------- | ------- |
| US-301 | As Alex, I want the system to automatically link related thoughts so that I see patterns I missed             | P0       | Alex    |
| US-302 | As Maya, I want a daily cognitive digest summarizing themes so that I can reflect on my thinking              | P1       | Maya    |
| US-303 | As Sam, I want the system to suggest unexpected connections between ideas so that I find creative inspiration | P1       | Sam     |
| US-304 | As Alex, I want to be alerted when my thinking shows a cognitive bias so that I can course-correct            | P2       | Alex    |
| US-305 | As Maya, I want to visualize my knowledge graph so that I see the shape of my understanding                   | P1       | Maya    |

---

## Epic 4: Account & Settings

> _User management and personalization._

### Stories

| ID     | Story                                                                                              | Priority | Persona |
| ------ | -------------------------------------------------------------------------------------------------- | -------- | ------- |
| US-401 | As a new user, I want to sign up quickly so that I can start capturing thoughts immediately        | P0       | All     |
| US-402 | As a user, I want to customize my interface (dark mode, font size) so that the tool feels personal | P1       | All     |
| US-403 | As a user, I want to export my data so that I maintain ownership of my thoughts                    | P1       | All     |
| US-404 | As a user, I want to delete my account and all data so that I have full control                    | P0       | All     |
