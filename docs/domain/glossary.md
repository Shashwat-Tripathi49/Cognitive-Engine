# 📖 Domain Model Glossary

> Authoritative definitions for every domain object, metric, event, and context in the Cognitive Engine Domain Model.

---

## Terms & Definitions

### Algorithmic Confidence

A mathematically calculated score ($0.00 \text{ to } 1.00$) produced by the `Cognitive Engine` evaluating pattern density, vector distance, and sample size. It never originates from an LLM.

### Bounded Context

An explicit boundary within which a domain model applies, owned strictly by one of the six frozen domain engines.

### Cluster

An algorithmically discovered spatial grouping of `Memory Nodes` in vector space using deterministic density algorithms (e.g., HDBSCAN).

### Cognitive Fragment

The atomic, normalized, immutable representation of raw user thought ingested by the `Capture Engine`.

### Decay Score

A dynamic metric ($0.00 \text{ to } 1.00$) tracking the temporal relevance and retrieval frequency of a `Memory Node`.

### Embedding

A high-dimensional vector representation of a `Memory Node` used for semantic distance calculations.

### Evidence Chain

An immutable, unbroken root proof container linking high-level patterns and reflections down to raw `Cognitive Fragments`.

### Evidence Reference

An individual link inside an `Evidence Chain` connecting a specific assertion to a `Graph Node`, `Graph Edge`, `Memory Node`, and `Cognitive Fragment`.

### Evidence Provenance

An audit record containing algorithm signatures, timestamps, and cryptographic hashes verifying evidence authenticity.

### Graph Edge

A directional, typed relationship connecting two `Graph Nodes` in the `Knowledge Graph Engine`, backed by source memory evidence.

### Graph Node

A canonical entity (concept, person, tool, event) managed by the `Knowledge Graph Engine`.

### Knowledge Graph Subgraph

A coherent slice of interconnected `Graph Nodes` and `Graph Edges` representing a contextual neighborhood.

### Memory Node

An encoded unit of knowledge wrapping a `Cognitive Fragment` with vector embeddings and decay metadata.

### Metacognitive Reflection

A natural language explanation generated by the `Reflection Engine` that describes how a user thinks based strictly on a validated `Evidence Chain`.

### Pattern

A recurring structural, causal, or temporal configuration detected deterministically across memory clusters with occurrence count $\ge 3$.

### Reasoning Artifact

A verified logical proof or relationship discovery generated by the `Reasoning Engine` backed by an `Evidence Chain`.

### Reflection Report

A structured temporal collection of `Metacognitive Reflections` covering a specific time window (e.g., weekly summary).

### Source Reference

Metadata capturing the origin URI, device, or modality of a `Cognitive Fragment`.

### Temporal Sequence

An ordered time-series sequence of thoughts or entity state changes sorted by capture timestamp.
