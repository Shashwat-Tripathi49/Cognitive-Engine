## Purpose

These guidelines ensure that:

1. **Any engineer** can set up the project in under 15 minutes
2. **All code** follows consistent patterns regardless of author
3. **PRs are efficient** — reviewers know what to look for
4. **Quality is automated** — linting, formatting, and testing catch issues before review
