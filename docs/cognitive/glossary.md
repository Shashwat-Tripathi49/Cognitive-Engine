# Glossary

> Authoritative definitions for all domain terminology used across Cognitive Engine documentation.

---

## Core Concepts

### Cognitive Engine System

The complete architecture of six interacting domain engines that augments human cognition.

### Capture Engine

The ingestion boundary engine that normalizes multi-modal raw user input into immutable `Cognitive Fragments`.

### Memory Engine

The persistence and retrieval engine that manages `Memory Nodes`, vector embeddings, and decay states.

### Knowledge Graph Engine

The topology engine that manages canonical entities (`Graph Nodes`) and typed directional relationships (`Graph Edges`).

### Cognitive Engine (Deterministic)

The 100% deterministic calculation engine that computes vector spatial density (`Clusters`), time-series (`Temporal Sequences`), patterns, and `Algorithmic Confidence`. **Zero LLM participation.**

### Reasoning Engine

The logical proof engine that verifies relationship hypotheses against graph topology and constructs immutable `Evidence Chains`.

### Reflection Engine

The metacognitive synthesis engine that translates validated evidence into natural language prose (`Metacognitive Reflections`). **LLM explains validated findings.**

---

## Domain Objects & Metrics

### Cognitive Fragment

The atomic, normalized, immutable unit of raw user input ingested by the Capture Engine.

### Memory Node

An encoded unit of knowledge wrapping a Cognitive Fragment with vector embeddings and decay metadata.

### Graph Node (Entity)

A canonical concept, person, tool, or event in the Knowledge Graph.

### Graph Edge (Relationship)

A directional, typed structural relationship linking two Graph Nodes, supported by Memory Node evidence.

### Algorithmic Confidence

A mathematically calculated score ($0.00 \text{ to } 1.00$) produced deterministically by the Cognitive Engine based on vector density, graph connectivity, and sample size ($N \ge 3$). Never generated by an LLM.

### Evidence Chain

An immutable proof container linking reasoning artifacts down to supporting Graph Nodes, Memory Nodes, and Cognitive Fragments.

### Metacognitive Reflection

A human-readable prose explanation generated by the Reflection Engine describing how the user thinks based strictly on a verified Evidence Chain. Zero recommendations or advice.
