## Design Philosophy

Cognitive Engine's UX is guided by three principles:

1. **Invisible Complexity** — The AI is powerful; the interface is simple
2. **Thought Speed** — Every interaction is optimized for the speed of thought
3. **Calm Technology** — The product assists without demanding attention

## Collaboration

- Designers: Update design system and wireframes via PR
- Engineers: Reference design system tokens in all UI code
- Product: Validate user flows against user stories
